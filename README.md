# 🕌 SabrTime

SabrTime is a simple Islamic web app designed to help people find peace and patience through powerful duas and reflection.

## ✨ Features

- 🤲 Duas for different moods
- ⏳ 60-second reflection timer
- 📤 Share duas easily on WhatsApp
- 🌙 Clean and simple Islamic design

## 📱 How it works

1. Select your mood
2. Read a helpful dua
3. Take a moment to reflect
4. Share the dua with others

## 🛠 Built With

## 📖 Purpose

The goal of SabrTime is to help people remember Allah during difficult moments and practice patience (Sabr).
