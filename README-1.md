## ✨ Features

### 📿 Duas & Remembrance
- **200+ Authentic Duas** — From Quran & Hadith, with Arabic, English translation & source
- **10 Categories** — Morning, Evening, Anxiety, Health, Travel, Forgiveness & more
- **Mood-Based Guidance** — Select your mood → receive the perfect dua
- **Daily Dua** — New dua every day, automatically
- **Islamic Guidance Chat** — Type how you feel → get Islamic advice & duas

### 🕌 Prayer & Ibadah
- **Prayer Times** — Accurate, location-based (Aladhan API)
- **Daily Ibadah Tracker** — Track Fajr, Quran, Dhikr, Maghrib & more
- **Tasbeeh Counter** — Personal + Global community count
- **60s Sabr Reflection Timer** — One minute of quiet dhikr
- **Qibla Direction** — GPS-based compass
- **Islamic Calendar** — Full Hijri calendar with upcoming events

### 🏆 Gamification
- **Sabr Points System** — Earn points for every ibadah
- **12 Islamic Badges** — First Dua, Tasbeeh Pro, Ibadah Hero & more
- **6 Spiritual Levels** — Seeker → Believer → Devoted → Guardian → Champion → Legend
- **Daily Streak Tracker** — 21-day visual calendar
- **Spiritual Health Score** — Weekly ibadah analytics

### 🌟 Unique Features
- **😰 Tap When Stressed** — One tap → instant calming dua + vibration
- **✨ 99 Names of Allah** — Learn one name daily with reflection
- **📊 Spiritual Health Score** — Track your weekly spiritual progress
- **💬 Islamic Guidance Chat** — Keyword-based dua suggestions

### ⚙️ Settings & More
- **9 Languages** — English, Arabic, Hindi/Urdu, Indonesian, Turkish, Bengali, French, German, Malay
- **Dark Mode** — True black OLED-optimized
- **Push Notifications** — Prayer & dua reminders
- **Offline Support** — Works without internet (Service Worker)
- **Ebook** — "Guidance to Jannah" — Islamic spiritual guide

## 🚀 Tech Stack

```
Frontend:   Vanilla HTML + CSS + JavaScript (Single file PWA)
Hosting:    GitHub Pages (Free)
APIs:       Aladhan (Prayer Times), Browser Geolocation
Storage:    localStorage (Privacy-first — no server)
PWA:        Service Worker + Web App Manifest
Fonts:      Lateef + Amiri (Islamic Arabic fonts)
```

## 📱 PWA Installation

### Android (Chrome):
1. Open `https://kyunus175.github.io/sabrtime/`
2. Tap **"Add to Home Screen"** banner
3. Tap **Install**

### iOS (Safari):
1. Open in Safari
2. Tap Share button → **"Add to Home Screen"**

### Desktop:
1. Open in Chrome
2. Click install icon in address bar

## 📂 Project Structure

```
sabrtime/
├── index.html          # Entire app (single file PWA)
├── sw.js               # Service Worker (offline support)
├── manifest.json       # PWA manifest (maskable icons)
├── sitemap.xml         # SEO sitemap
├── robots.txt          # Search engine instructions
└── privacy-policy.html # Privacy policy
```
